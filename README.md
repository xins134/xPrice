# xPrice

面向个人使用的 A 股自选行情工具，包含原生 iPhone App、Apple Watch App 和表盘行情组件。支持指数、场内 ETF、LOF 和沪深可转债，自选列表由手机管理，手表同步后可以自行联网获取报价。

## 已确认的首版范围

- 手机支持证券名称／代码搜索、添加、删除、排序和本地保存。搜索在停止输入 0.5 秒后发起，继续输入会重新计时。
- 主页面在对应自选 cell 的名称旁用手表图标标记“表盘关注”。表头上方提供横向滑动行情栏，可搜索或从自选中连续添加多个指数、个股；通过“管理”调整顺序、移除，最多独立保存 50 只。行情栏置于分组列表的表头，卡片不受列表行外层圆角裁剪。
- iPhone 自选详情可开启「显示在熄屏行情」，所有现有自选均可选择，选择仅保存在手机本机，按自选顺序显示；删除或替换自选时清理失效选择。首页右上角「一键熄屏」打开纯黑全屏页，在底部安全区内显示涨跌幅，每行最多 4 个，多行展示；字号与首页自选相同，沿用设置中的涨跌色，无行情显示 `—`。单击其他区域立即隐藏行情并暂停定时刷新、取消在途取价；再次单击立即显示并立即刷新，随后恢复原有定时刷新策略。底部行情容器始终可点击返回首页，包括行情隐藏时；退出后首页恢复正常刷新。页面进入与退出采用整页淡入淡出，亮度在约 0.4 秒内渐变至 10%，手动退出时渐变恢复原亮度。模式在前台防止自动锁屏；进入后台保留页面及行情显示／隐藏状态，暂停刷新并恢复系统亮度与自动锁屏设置；回到前台后重新渐变至 10%，仅在行情显示时恢复刷新。这是 App 内模拟熄屏，底部系统横条的自动隐藏由 iOS 控制。
- iPhone 个股详情页导航栏右上角也提供「熄屏」按钮，仅显示当前证券，无需先开启「显示在熄屏行情」，也不会修改首页的熄屏选择。隐藏／显示、刷新、后台保留、亮度渐变及点击行情区域返回首页的行为与首页入口相同。
- 首版最多保存 50 只自选。ETF、LOF 展示场内交易价格，不是基金单位净值。
- 可转债支持名称、部分名称和完整代码搜索，可加入自选、首页行情栏及表盘关注，并参与备份与手表同步。交易代码覆盖沪市 `110`、`113`、`118` 和深市 `123`、`127`、`128` 前缀；申购、配售及可交换债代码不在本轮范围内。
- 展示现价、相对上一交易日收盘价的涨跌幅、证券代码、行情时间及数据状态。
- 手机证券详情的报价卡片内右上角提供「在东方财富查看」跳转图标，通过 `eastmoney://page/stockpage?code=…&market=…` 打开对应页面；沪市使用 `market=1`，深市和北市使用 `market=0`，无法打开时提示检查是否安装东方财富 App。
- 手机和手表分别提供 1、3、5、10、15 秒刷新设置，默认分别为 3 秒、5 秒。
- 手机和手表设置均可切换腾讯、东方财富、新浪行情，默认腾讯；来源选择保存在本机并同步，表盘组件也使用所选来源。
- Watch App 展示自选列表和单只证券详情。表盘显示选中的一只证券，点击打开对应详情。
- iPhone 设置提供「跟随系统／浅色模式／深色模式」，默认跟随系统，选择即时生效并保存。支持动态字体和红涨绿跌／绿涨红跌。股票和指数展示两位价格小数，基金与可转债的价格及涨跌额展示三位。
- 手机和手表设置提供六种按钮主题色：青绿（默认）、蓝色、紫色、橙色、玫红、石墨。选择即时生效、保存并同步到配对设备；行情涨跌颜色独立设置。
- 手机和手表在「设置 → 界面外观 → 字体大小」提供小、较小、中、较大、大五档，默认较小，保持原有字号。选择即时生效、保存并同步到配对设备；也支持系统动态字体，行情栏与熄屏行情随字号调整。
- 默认开启交易时段智能刷新：北京时间工作日的集合竞价和交易时使用原有档位，午休 60 秒，其余时段 300 秒。按周一至周五判断；法定节假日可在手机设置补充休市日期，并同步到手表。进入前台与手动刷新均立即请求。
- 手机首页的行情栏和自选列表采用紧凑样式，不显示来源、更新时间或缓存标签；手机详情、手表和表盘显示源时间及实际报价来源，并标记取价失败、旧来源缓存和较早的源时间。
- 设置展示对端保存后的上次确认时间与自选数量，提供重新同步。手机支持 JSON 自选备份、导入预览、默认合并及替换二次确认，导入不会静默截断超过 50 只的列表。
- 目标设备为 iPhone 14 Pro Max（iOS 27）和 Apple Watch Series 8（watchOS 26）；工程最低系统为 iOS 26、watchOS 26。

## 打开与运行

1. 用完整 Xcode 打开 `xPrice.xcodeproj`。工程不需要 CocoaPods、第三方 Swift 包或 XcodeGen。
2. 在 `Configuration/Local.xcconfig` 修改 `XPRICE_IOS_BUNDLE_ID` 和 `XPRICE_APP_GROUP`，使用属于自己的唯一标识。Watch 与组件的 Bundle ID 会自动派生。
3. 填写 `DEVELOPMENT_TEAM`，或在三个 target 的 **Signing & Capabilities** 中选择同一个 Apple Developer 团队。为三个 target 注册并启用同一个 App Group。
4. 真机运行选择 `xPrice` scheme 和 iPhone。配对 Apple Watch 后运行 `xPriceWatch` scheme，或通过手机 Watch App 安装。
5. 首次使用先在手机添加自选，再打开一次手表 App 完成同步。在设置中指定表盘证券，然后编辑表盘，添加 xPrice 组件。

App Group 用于同一设备上的 App 与组件共享数据，不会自动在手机和手表之间共享文件；两台设备之间通过 WatchConnectivity 同步。所选签名团队需要支持配置 App Groups。如果账号无法启用该能力，表盘组件无法读取 Watch App 的自选和缓存，需要先解决签名能力。此工程没有预置任何团队、证书或付费账号，也没有执行设备安装。

组件支持圆形、矩形和单行位置，不同表盘能够提供的位置不同。App 尚未同步自选时，组件会提示打开 App。

## 行情来源与刷新行为

在「设置 → 行情来源」选择腾讯、东方财富或新浪，三个来源均不需要在 App 内填写 API Key。默认仍为腾讯，旧版自选和设置可继续读取。选择会保存并同步到配对手表；手机、手表以及表盘组件统一使用该选择。App 在前台切换后立即重新请求，切换前尚未完成的报价和搜索不会覆盖新的请求结果；接口失败时继续显示最近有效报价。当前为手动选择来源，所选接口失败时不会自动改用其他来源。

| 来源 | 报价端点 | 搜索端点 | 解析口径 |
| --- | --- | --- | --- |
| 腾讯 | `https://qt.gtimg.cn/q=…` | `https://proxy.finance.qq.com/cgi/cgi-bin/smartbox/search` | 报价为 GB18030 文本；新版 JSON 搜索支持股票、基金和可转债，按完整代码去重 |
| 东方财富 | `https://push2.eastmoney.com/api/qt/ulist.np/get` | `https://searchapi.eastmoney.com/api/suggest/get` | 使用 `fltt=2` 的小数价格，`f124` 为源时间；搜索 token 为网站公开客户端标识 |
| 新浪 | `https://hq.sinajs.cn/list=…` | `https://suggest3.sinajs.cn/suggest/…` | GB18030 文本，按现价与昨收计算涨跌幅，保留日期和时间；请求带新浪 Referer |

这些是网站公开端点，本项目未获得稳定性、覆盖范围、更新延迟或商用分发授权承诺，接口结构、可用性和限流可能变化。客户端按选定频率请求不构成行情延迟保证；应用以接口提供的行情时间为准，不会把请求时间当作成交时间。ETF、LOF 均展示场内价格。

三个适配器通过 `MarketDataProviders` 按设置创建，均使用 HTTPS、最多 50 只一批以及超时、响应校验和取消保护。证券用市场前缀加六位代码标识，例如 `sh600519`、`sh510300`、`sz161725`、`sh113052`、`sz127045`。搜索 `000001` 会分别匹配上证指数（`sh000001`）和平安银行（`sz000001`），两者可以同时加入自选；指定 `sh000001` 或 `000001.SH` 则只查询上证指数。可转债可搜索“兴业转债”“牧原转债”，或输入 `113052`、`127045.SZ` 等完整代码。名称搜索依赖所选来源的搜索端点；腾讯使用新版网站 JSON 搜索，新浪请求包含债券类别 `81`，东方财富沿用 `type=14`。完整代码搜索会先查到有效报价再允许添加，避免把无效代码写入自选。

手机、手表仅在 App 活跃前台自动刷新。退到后台、手机锁屏、手表垂腕进入 inactive 后，取消循环及请求，并立即释放刷新状态；重新进入前台立即发起新请求。旧请求即使迟到也不会提交或清除新请求状态。请求失败会退避重试，避免在接口不可用时每秒重复请求。

「设置 → 前台刷新间隔」可关闭智能刷新，关闭后所有前台时段使用原有刷新档位。开启时按北京时间的周一至周五判断：09:15–09:30 集合竞价、09:30–11:30 和 13:00–15:00 交易；午休每 60 秒，盘前、收盘后、周末和自定义休市日每 5 分钟请求。在下一个开盘或其他时段边界提前唤醒，手动刷新不受时段限制。用户已选择工作日规则，不内置年度节假日表；法定节假日请在「设置 → 前台刷新间隔 → 休市日期设置」补充。

手机详情、手表及表盘展示行情源时间与实际来源，手机首页保持名称、代码、价格和涨跌幅的紧凑展示。失败时保留旧价格，切源后旧报价保留自身来源；首选来源的有效报价可替代旧来源缓存，即便源时间稍早。同一来源仍按行情时间和接收时间避免倒退。详情等状态展示中，交易时段超过 5 分钟的源时间仅标记“源时间较早”，不据此认定停牌或接口延迟。涨跌色保持独立。

同步“已发送”表示排队或发出，收到并保存成功后才回复确认。设置中的上次确认时间和数量是历史记录；新的设置或列表编辑需要新的确认，旧确认不能代替它。可在手机或手表点“重新同步”。旧版对端不能解码包含可转债的新类型数据，也不能确认新功能的设置版本；使用可转债前请同时更新手机和手表 App。新版可继续读取旧版自选及备份。

「设置 → 数据管理 → 自选备份与恢复」可将自选、行情栏和设置保存为 JSON 文件，不包含行情缓存或同步记录。导入先显示数量与合并结果，默认保留当前设置；可选恢复备份设置，或选择替换列表并二次确认。损坏文件、未知格式版本、超过 1 MB 或导入后超过 50 只会明确失败，现有列表保留。

表盘组件由 WidgetKit 调度，时间线请求约 15 分钟后的更新机会，并可由手表 App 请求重新加载；系统决定实际执行时间，不能保证分钟级或秒级准点。组件会直接尝试获取所选证券的报价，失败时使用缓存和原有行情时间。

2026-11-09 已通过实际 Swift 适配器在交易时段进行只读联网检查：腾讯、东方财富、新浪均完成“兴业转债”“牧原转债”的名称搜索、代码搜索和三位小数报价获取，并保留各自的报价来源与源时间。腾讯新版搜索还检查了股票、指数、ETF 和 LOF。自动化测试使用明确标注的合成样例；此次联网检查只代表当时这些样本可用，手机和 Watch 真机网络访问及长期接口表现仍需设备验收。

## 交易时段验收
