# 本轮完善计划

用户已授权实现四项。采用北京时间周一至周五规则，法定节假日由用户手动补充；不依赖在线年度日历。

| 项目 | 行为 | 验收标准 |
| --- | --- | --- |
| 前台恢复刷新 | 后台立即取消循环和请求；重新活跃时立即发起新请求 | 旧请求即使忽略取消并迟到，也不能阻塞或覆盖新请求；失败后可重试 |
| 智能刷新 | 默认开启；集合竞价/交易使用现有档位，午休 60 秒，其余 300 秒；手动刷新不受时段限制 | 上海时区、周末、自定义休市与各时段边界准确；开盘边界立即唤醒；开关与休市日期双端独立同步 |
| 行情状态 | 手机详情、手表和表盘显示实际来源与源时间，分别描述未取价、失败缓存、旧来源缓存、交易阶段；首页按用户要求保留紧凑样式 | 旧缓存来源未知时明确提示；较早的源时间不被直接判断为接口延迟或停牌；首页不显示来源、更新时间或缓存标签；涨跌色保持独立 |
| 同步与备份 | 收到并保存后确认，展示上次确认时间/数量，支持重试；JSON 导出、预览后导入 | 旧回执不确认新编辑；导入默认合并，不恢复设置；替换二次确认；超出 50 只、损坏或过大文件明确失败 |

核心策略和竞态由无需模拟器的自动化测试验证；完整构建覆盖 iPhone、Watch 与表盘组件。交易时段真实端点、配对手表接收确认、系统文件选择器与耗电需设备验收，构建成功不代表这些场景已实测。

表盘网络刷新仍由 WidgetKit 调度，本轮不承诺秒级后台报价或到价通知。

## 实施结果（2026-11-08）

四项代码已完成并接入两端设置。110 项自动化测试通过；完整未签名 iPhone、Watch 和表盘组件构建通过，工程文件结构校验通过。涨跌颜色与按钮主题保持独立。

手机入口：前台刷新间隔中的智能开关与休市日期、Apple Watch 中的重新同步与上次确认、数据管理中的自选备份与恢复。手表提供智能开关和重新同步。
